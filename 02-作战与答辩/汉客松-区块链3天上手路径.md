## 零、先纠正一个方向：你要学的不是区块链，是「怎么把链接到你的产品上」

你有全栈底子（JS/Node/Vue3/Python/FastAPI/部署），**这些在链上开发里全都用得上**——调合约就是一个 HTTP 请求的替代品，写合约就是写后端逻辑。

你真正缺的只有两件事：
1. **一个心智模型**（链上的东西和数据库哪里不一样）
2. **四个动作**（发交易、部署合约、网页调合约、把外部数据喂进去）

三天足够。**别去学共识算法、密码学、代币经济——那是别人的事。**

## 一、3 天要搞懂的全部概念：就 6 个

用你最熟的东西类比，10 分钟能懂：

| 概念 | 一句话 | 类比 |
|---|---|---|
| **账户** | 一对密钥。地址 = 账号，私钥 = 签名权 | 银行卡号 + U 盾，**丢了没人能帮你找回** |
| **交易** | 你签名的一条「我要改这个数据库」的请求 | 一条只能追加、不能修改的 SQL |
| **gas** | 改一次数据要付的手续费 | 写入数据库的服务器成本 |
| **合约** | 存在链上的**一段代码** | 一个部署后再也改不了的微服务 |
| **测试网** | 一条假链，币是免费的 | 沙箱环境 |
| **EVM 兼容** | 学会以太坊，代码能跑几十条链 | 学会一种 SQL 方言 |

**最关键的一条认知**（对金融背景的你们最好懂）：

> **智能合约 = 一份自动执行的合同。条款写在代码里，没有仲裁者，没有人能单方面改。**

这就是为什么它跟保险天生一对——**保单最贵的那部分成本，是「证明该赔」和「相信对方会赔」。**

**一次交易的完整生命周期**（背下来，演示时要用）：
```
你签名 → 广播到节点 → 进入交易池 → 被打包进区块 → 全网确认 → 状态永久改变
                        ↑ 这里要等 10~30 秒，演示时要预留时间
```

#### Step 2 · 部署你的第一个合约（60–90 分钟）

打开 **Remix**：`https://alpha.remix.live/` ← **⚠️ 不要用 `remix.ethereum.org`，你这台机器直连超时**

（浏览器里写合约，**零环境配置**——三天内不要碰 Hardhat/Foundry）

先跑一个最短的，确认链路通了：

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

contract Hello {
    uint256 public value;
    function set(uint256 v) external { value = v; }
    function get() external view returns (uint256) { return value; }
}
```

**具体流程（左上角三块面板：FILE EXPLORER / 图标栏 / 编辑器）**：

1. 进 Remix 后先点 **`Start Coding`**（不要点 Create a new workspace，那会多一步选模板）
2. 左侧 **FILE EXPLORER** 里展开 `contracts` 文件夹 →
   - 里面**没有** `Hello.sol` → **右键 `contracts` → New File**，输入 `Hello.sol`（**`.sol` 后缀必须带**）
   - 里面**有** → 交给下一步
3. **在左侧单击 `Hello.sol`**，让它出现在中间的编辑器里 → 把上面的代码粘进去 → `Ctrl+S`
4. 左侧图标栏点 **Compile** → 按钮上会显示 `Compile Hello.sol` → 点它 → 变**绿色对勾**表示通过
5. 左侧图标栏点 **Deploy** → Environment 保持默认的 **`Remix VM`**（这步不用钱包、不花币）
   → 确认合约那一行显示 **`✓ Compiled`** → 点面板**最底部那个大按钮 `Deploy`**（**浅蓝色，不是橙色**，别去找橙色）
6. 下方出现 **Deployed Contracts** → 展开 → 调 `set(42)`，再点 `get()` → **读到 42 就成了**

> 🔧 **如果 Compile 面板显示 `No file selected.`** —— 这不是编译失败，
> 是**编辑器里没打开任何文件**（编译按钮的文字是跟着当前打开的文件走的）。
> 回到第 3 步：**在左侧文件树里单击 `Hello.sol`**，让它出现在中间编辑器里，再点 Compile。
> ⚠️ 顺手排两个常见错：① 新建文件时**漏了 `.sol` 后缀**（右键 Rename 补上）；

#### Step 4 · 做「喂价者」——这一步决定你能不能演示（2–3 小时）

**先理解问题**：合约**不能主动访问互联网**。
因为链是确定性的——全世界每个节点跑同样的代码必须得到同样的结果，如果合约能随时去调一个 API，结果就不可能一致。
所以：**外部数据必须由链下的某个东西「写进去」。**

这个东西叫**预言机（oracle）**。

**⚠️ 我查过的一个技术真相，直接影响你的方案**：
> **Chainlink 的 Data Feeds 里没有降雨量数据。** 它现在覆盖的是加密货币、美股、外汇、贵金属、商品这些**金融类**数据。
> 所以「接一个现成的降雨喂价」这条路走不通。

**你的方案：自己跑一个喂价者。** 一个定时脚本，抓天气 API，写进合约：

const ADDR   = "0x你的合约地址";

async function push() {
  const mm = await fetchRainfall("wuhan");          // ← 接你的天气 API
  const provider = new JsonRpcProvider(RPC);
  const wallet   = new Wallet(KEY, provider);
  const c        = new Contract(ADDR, ABI, wallet);
  const tx = await c.updateRainfall(1, Math.round(mm));
  await tx.wait();
  console.log("pushed", mm, "mm →", tx.hash);
}
```

**可用的合约骨架**（直接改，别从零写）：

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

contract RainDeliveryInsurance {
    address public operator;                              // 喂价者 = 你的脚本
    uint256 public constant PREMIUM   = 0.001 ether;      // 保费
    uint256 public constant PAYOUT    = 0.01  ether;      // 赔付
    uint256 public constant THRESHOLD = 50;               // 触发阈值 50mm

    struct Policy {
        address rider; uint8 regionId;
        uint256 startTime; uint256 endTime;
        bool paid; bool exists;
    }

    mapping(uint256 => Policy)  public policies;   // policyId => 保单
    mapping(uint8   => uint256) public rainfall;   // regionId => 降雨量
    uint256 public nextPolicyId;

    event PolicyBought(uint256 indexed policyId, address indexed rider, uint8 regionId);
    event RainfallUpdated(uint8 indexed regionId, uint256 mm);
    event ClaimPaid(uint256 indexed policyId, address indexed rider, uint256 amount);

    constructor() { operator = msg.sender; }

    function buyPolicy(uint8 regionId, uint256 hours_) external payable {
        require(msg.value == PREMIUM, "premium mismatch");
        uint256 id = nextPolicyId++;
        policies[id] = Policy(msg.sender, regionId,
                              block.timestamp, block.timestamp + hours_ * 1 hours, false, true);
        emit PolicyBought(id, msg.sender, regionId);
    }

    function updateRainfall(uint8 regionId, uint256 mm) external {
        require(msg.sender == operator, "not operator");
        rainfall[regionId] = mm;
        emit RainfallUpdated(regionId, mm);
    }

    function claim(uint256 policyId) external {
        Policy storage p = policies[policyId];
        require(p.exists,              "no such policy");
        require(!p.paid,               "already paid");
        require(block.timestamp <= p.endTime,      "policy expired");
        require(rainfall[p.regionId] >= THRESHOLD, "threshold not met");
        p.paid = true;
        payable(p.rider).transfer(PAYOUT);
        emit ClaimPaid(policyId, p.rider, PAYOUT);
    }
}
```

**这份合约里有三个「演示时会发光」的设计**，讲的时候要点出来：
- `updateRainfall` 只有 `operator` 能调 → **权限是写死的，不是靠自觉**
- `claim` 里的四条 `require` → **拒绝赔付的理由全部公开可查，没有暗箱**
- `emit` 出来的 event → **每一次状态变化都留在链上，可追溯**

## 八、备选路线：完全不用浏览器插件（Node 脚本部署）

**前提**：本机有 Node（命令行敲 `node -v` 能出版本号就行）。

```bash
mkdir rain-insurance && cd rain-insurance
npm init -y
npm i ethers dotenv
```

**① 从 MetaMask 取私钥**：账户详情 → 找 **「显示私钥 / Show private key」** → 输密码 → 复制那串 `0x...`

> 1. **这个钱包只用于测试网，永远不要往里放真钱。** 一旦放了真钱，这串私钥就等于你的全部身家。
> 2. 私钥**只写在本地 `.env` 文件里**，并且**立刻把 `.env` 写进 `.gitignore`**。
> 3. **绝不粘贴到任何网页、聊天窗口、或发给任何人**（包括我）。

**📁 脚手架已经做好了，在 `桌面\汉客松-部署脚本\`**：

## 0. 用户诉求与本轮产出

**用户诉求（原文）**：「我希望有严谨的计算算出具体赔付比例（即杠杆率），而不是自定。」

**产出**：`10-金融与定价/杠杆率推导.md` —— 把杠杆从「拍的 10 倍」改成**由目标赔付率反解**：

```
L = R* / p        （R* = 60%，p = 该区域 72h 窗口触发概率）
```

## 1. 主理人对每份专家交付的核验（逐项）

### 1.1 数据工程师（数据质量与统计口径）

**交付要点**：三条数学关系（保本 `L<1/p`、恒等 `R=p×L`、反解 `L=R*/p`）**全部正确**，但只在「同一保单/同一区域/同一时长窗口」内成立；`L` 必须锚 `R*` 而非保本线；统一 L 失效条件 `max(p_i) × L > 1` → 广州 `L > 8.68` 必亏。另报三个质量问题 A/B/C。

**主理人核验**：

| 项 | 核验方式 | 结果 |
|---|---|---|
| 三条数学关系 | 代数验算 | ✅ **正确**，主理人独立写出的推导链与其一致（见 `杠杆率推导.md` §2） |
| `max(p)×L>1` 失效条件 | 用权威 p 重算 | ✅ **正确**：`1/0.11524 = 8.676`，现价 `L=10 > 8.68` |
| **链上现价实际赔付率 59.5/57.0/56.6/57.6/53.1%** | **主理人用 `actuary-output.json` 独立复算** | ✅ **完全一致**，五城均值 **56.8%** ← **本轮最强证据**（见下 §2） |
| 问题 A（浮点累加漂移） | 主理人读 `cache/guangzhou-*.json` 重跑两种累加方式 | ✅ **属实**：精确逐窗口相加 **11149** vs 增量累加 **11105**，差 **44**；p 精确 **11.5700%** vs JSON **11.5244%** |
| 问题 B（2026 残缺年） | 主理人实算逐年窗口数 | ✅ **属实**：广州逐年窗口数 `2016:8784, 2017–2025:8760/8784, **2026:6481**`（其他城市同构）；`perYear72h` 无 `windows` 字段，实际从 `hits` 可辨：广州 2026 hits=1001 vs 2025 全年 1030 |
| 问题 C（fileHash 换行口径） | 主理人对 `actuary-output.json` 实测两种哈希 | ✅ **属实**：LF 归一化 `0xe02065273d885f244a837f1711594fa18c2451819dd995d25c00ae6133cdfcf8`（= 存档值）；CRLF 原文 `0x9a942d29e5342669a0636fbf733370506fa949aeb24ac06ffa6cdef38f005c58`（**不同**）。文件确为 CRLF 存储 |
| 数据本身干净 | 复核其声明 | ✅ null/负值/断点/重复全为 0（主理人未逐项重跑，采信但其口径与观测一致） |

## 2. 本轮最强证据：链上现价早已按 R*=60% 执行

**数据工程师发现、主理人独立复算一致**：

| 城市 | 链上现价 | p(72h) | 现价对应 L | **实际赔付率 R** |
|---|---:|---:|---:|---:|
| 武汉 | 0.0008 | 4.756% | 12.5 | **59.5%** |
| 上海 | 0.0008 | 4.557% | 12.5 | **57.0%** |
| 北京 | 0.0004 | 2.265% | 25.0 | **56.6%** |
| 广州 | 0.0020 | 11.524% | 5.0 | **57.6%** |
| 成都 | 0.0007 | 3.719% | 14.3 | **53.1%** |
| | | | **均值** | **56.8%** |

**这条为什么最重要**：

1. 它把「目标赔付率 60%」从**事后解释**变成**链上已执行的事实** —— 五个价格全部落在 53%–60%，不可能是巧合。
2. 它**同时解释了** `PREMIUM = 0.001 ether` 的地位：那只是 `03-合约/RainDeliveryInsurance.sol:20` 的**默认值**，`premiumOf()` 实际读 `aiPremium[regionId]`（`:125-128`）。**「10 倍杠杆」不是我们的定价，是没人用的默认值。**
3. 它给答辩一个**无法被打脸**的句式：不要说「我们的杠杆是 10 倍」，要说「**我们的目标赔付率是 60%，链上现价的实际赔付率是 53%–60%，杠杆由 `L = R*/p` 反解**」。
